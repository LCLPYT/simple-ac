# simple-ac
Simple anti-cheat for Minecraft servers.
Written as Fabric mod using Kotlin.

**This project is still in alpha and should not be used in production yet.**

## Features

### Anti Auto Clicker
Detects the usage of auto clickers and kicks players when they are repeatedly flagged for using it.

## Development
### Running the project
If you don't see any run configurations in IntelliJ IDEA, try reopening the project.

If the run configurations have a red error sign on them:
- close the project
- remove the `.idea/` and `.gradle/` folders from CLI or your file manager
- reopen the project, wait for Gradle sync to finish
- reopen the project one more time
